NOT WORKING / CRITICAL SECURITY ISSUES
================================================================================

1. **CRITICAL: API ENDPOINTS NOT PROTECTED** - MAJOR VULNERABILITY
   ✗ /api/admin/courses (GET/POST) - NO authentication check
   ✗ /api/admin/courses/[courseId] (GET/PUT/DELETE) - NO authentication check
   ✗ /api/admin/coupons (GET/POST) - NO authentication check
   ✗ /api/admin/coupons/[couponId] (GET/PUT/DELETE) - NO authentication check
   ✗ /api/admin/lessons (GET/POST) - NO authentication check
   ✗ /api/admin/lessons/[lessonId] (GET/PUT/DELETE) - NO authentication check

   IMPACT: 
   - Unauthorized users can access admin data via direct API calls
   - Complete bypassing of the layout-level auth protection
   - Any unauthenticated client can:
     * GET all courses, coupons, and lesson links
     * POST/create new courses, coupons, and lessons
     * PUT/update existing resources
     * DELETE resources entirely
   - This is a critical authentication bypass vulnerability

   EVIDENCE:
   - /src/app/api/admin/courses/route.ts - No verifyAdminSession() call
   - /src/app/api/admin/coupons/route.ts - No verifyAdminSession() call
   - /src/app/api/admin/lessons/route.ts - No verifyAdminSession() call
   - All [id] routes also missing authentication checks

   RECOMMENDATION: Add verifyAdminSession() check at start of each route handler
